# STM32 Projects

Projects for the STM32F407VG Discovery board, built with STM32CubeIDE.

| Project | Description |
|---|---|
| ALCD-Library | 16x2 alphanumeric LCD library (4-bit mode) and test program |

## Hardware
- STM32F407G-DISC1 (Discovery) board, programmed over the on-board ST-Link
- 16x2 character LCD (HD44780-compatible)

## How to open a project
1. Clone the repo: `git clone https://github.com/Tirdad371/stm32-projects.git`
2. In STM32CubeIDE: File -> Import -> Existing Projects into Workspace
3. Select the project folder and build
